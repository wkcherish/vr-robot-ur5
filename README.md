# 机械臂仿真项目

## 项目简介

该项目是一个基于 Vue 3 和 Three.js 的机械臂仿真应用，旨在提供一个可视化的界面，允许用户手动调整机械臂各个关节的运动，并与实际机械臂设备进行连接和交互。

## 技术栈

- **Vite**: 快速的前端构建工具
- **Vue 3**: 现代化的 JavaScript 框架
- **Three.js**: 用于创建和渲染3D图形的库
- **FastAPI**: 用于构建后端 API 的现代框架

## 功能

1. 手动调整机械臂各个关节的运动
2. 连接和断开机械臂设备
3. 回到初始视角位置
4. 动作模拟

## 机械臂要点

### actual_pos 数据结构

```javascript
actual_pos = [1.1046747520317388, -1.5141579898313877, -1.6297835540520333, -0.4636527600091554, 0.863356721232929, 0.012559659131761654];
```

### 机械臂结构

1. 与机械臂建立连接，返回的数据中用到的数据（actual_pos）是一个数组，表示机械臂各个模块的弧度值。
2. 大约每隔 1 秒接收一次数据。
3. 这些模块从下到上分别为（基座、肩部、肘部、手腕 1、手腕 2、手腕 3）。
4. 弧度的取值范围是 -2π 到 2π，弧度值从 0 到 2π，就是转了一整圈。
5. 肩部弧度值为 -0.5π 时，处于直立状态；肘部弧度值为 0 时，处于直立状态；手腕 1 弧度值为 -0.5π 时，处于直立状态。
6. 相对于基座，肩部、肘部、手腕 1 是垂直旋转的。

## 使用 Three.js 动态渲染机械臂

首先创建场景、相机和渲染器，渲染器负责渲染场景和相机。

### 在场景创建之后，即可做以下事情：

1. 解析加载 3D 模型
2. 创建并添加光线
3. 创建并添加辅助线
4. 创建并添加网格地板

### 在相机和渲染器创建之后，即可做以下事情：

1. 创建并使用控制器

### 在场景、相机和渲染器创建之后，并且渲染器被添加到页面之后，即可做以下事情：

1. 渲染画面（`renderer.render(scene, camera)`）

## 安装和运行

### 1. 克隆项目

```bash
git clone <项目仓库地址>
cd <项目文件夹>
```

### 2. 安装前端依赖

使用 npm 或 yarn 安装前端项目依赖：

```bash
npm install
# 或者
yarn install
```

### 3. 运行前端项目

使用以下命令启动前端开发服务器：

```bash
npm run dev
# 或者
yarn dev
```

### 4. 安装后端依赖

在后端目录中（通常是 `backend` 或类似的文件夹），使用 pip 安装 FastAPI 和其他依赖：

```bash
pip install fastapi uvicorn
```

### 5. 运行后端项目

使用以下命令启动 FastAPI 服务器：

```bash
uvicorn main:app --reload
```

### 6. 访问应用

在浏览器中打开 `http://localhost:3000`（前端）和 `http://localhost:8000`（后端）以访问应用。
